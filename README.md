# Careflow

## Run locally
Install dependencies with npm install, then run npm run dev
Open the Local URL printed by Next.js

## Day 1 Features
- Three synthetic referral records
- a controlled status filter
- a visible result count and empty state
- Seperate StatusFilter and ReferralList Components

## Current Limits
Data is hardcoded. The filter resets on full reload
Authentication and database persistence are planned later.
